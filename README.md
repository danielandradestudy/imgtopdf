# 🖼️ Image to PDF Web App (Vibe Coding Edition)

Este projeto nasceu de uma ideia simples: e se pudéssemos transformar scripts utilitários de linha de comando em ferramentas web acessíveis para qualquer pessoa em questão de minutos?

Recentemente, encontrei um script Python básico para conversão de imagens em PDF. Percebi que aquele código tinha potencial para ser muito mais útil se tivesse uma interface amigável. Decidi, então, testar o fluxo de **"Vibe Coding"** para acelerar essa transformação.

### 🤖 O Processo
Utilizando o **Gemini 3 Flash**, transformei a lógica original de CLI (Command Line Interface) em um Web App funcional e moderno. O foco não foi apenas escrever código, mas iterar rapidamente sobre a experiência do usuário e a funcionalidade, utilizando IA para pontear o abismo entre o script local e a aplicação web.

## ✨ Funcionalidades
* **Upload Intuitivo:** Arraste e solte suas imagens (JPG, PNG, JPEG, BMP).
* **Preview em Tempo Real:** Visualize a imagem carregada antes de gerar o documento.
* **Processamento em Memória:** Conversão segura e rápida utilizando `BytesIO`, sem necessidade de armazenamento temporário no servidor.
* **Download Instantâneo:** Baixe seu PDF finalizado diretamente pelo navegador.

## 🛠️ Tecnologias
* **Python 3.x**
* **Streamlit** (Interface Web)
* **Pillow (PIL)** (Processamento de Imagem)
* **Gemini 3** (AI Pair Programmer)


## 📝 O que é Vibe Coding?
O termo, que ganhou força na comunidade tech, refere-se ao estilo de desenvolvimento onde o foco principal do humano está na **visão do produto, na lógica de alto nível e no refinamento da ideia (a "vibe")**, enquanto a IA de ponta cuida da implementação técnica detalhada. Isso permite que ideias saiam do papel e se tornem ferramentas funcionais em tempo recorde.
